\section*{Summary}

Most of the application's data endpoints are connected from the frontend to the Django backend. The login page still points to an API route that is not defined by the backend. A separate QuickStats client has been added under the local \texttt{tests} folder to try USDA crop price data. That client is not part of the Django backend and is not connected to the frontend.

\section*{USDA NASS QuickStats external API}

The local test client requests QuickStats directly; this is not an application endpoint served by Django.

\begin{itemize}[leftmargin=1.5em, itemsep=0.55em]

\item \textbf{GET https://quickstats.nass.usda.gov/api/api\_GET/}
  \begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item Client: \texttt{tests/quickstats\_client/client.py}, callable as \texttt{fetch\_latest\_crop\_price}.
    \item Authentication: requires \texttt{QUICKSTATS\_API\_KEY} in the process environment; the client sends it as the \texttt{key} query parameter.
    \item Query: requests NASS \texttt{PRICE RECEIVED} records at state aggregation for the chosen commodity and state. It tries monthly records first and falls back to annual records if monthly records are absent.
    \item Result: the latest record found, including its report period, year, value, and unit. This is the latest published USDA estimate returned by the query, not a live market quote.
    \item Status: callable from the standalone test script \texttt{tests/market\_request\_test.py}; not yet exposed by Django or connected to the frontend.
  \end{itemize}

\end{itemize}

\section*{Key conclusions}

\begin{itemize}[leftmargin=1.5em, itemsep=0.5em]
\item The main field, crop planning, gear, account, environment, map, demo, and chat request paths reviewed have matching backend routes and frontend callers.
\item The login page URL has no matching backend route.
\item The standalone QuickStats client demonstrates an external USDA data connection only. A Django wrapper and frontend integration would still be needed to make crop price data available in the application.
\item The QuickStats value is a published price-received estimate with a period and unit, not a real-time commodity market price.
\end{itemize}
